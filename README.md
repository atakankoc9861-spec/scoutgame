# Gözcü: Scout Kariyeri

Futbol scout kariyer oyunu (Godot 4.5.1, Android). TR/EN.

- `autoload/` oyun durumu, veri, çeviriler, ses, donma bekçisi
- `sim/` maç motoru (live_engine.gd)
- `three/` 3D maç izleyici, ofis/hub, mocap oyuncular
- `ui/` arayüz
- `assets/man/` retarget edilmiş mocap animasyonları ve manken

Animasyon kaynakları: Quaternius Universal Animation Library (CC0), Anderson Rohr mocap paketleri (oyunda kullanım serbest, yeniden dağıtılamaz).
